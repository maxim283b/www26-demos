# WWW'26 Research Track

Статьи разложены по десяти фактическим трекам WWW'26. Во всех директориях находятся `pdf/` с
отдельными статьями и `index.tsv` с DOI и названием; для треков 1–8 также сохранён исходный
диапазон страниц монолитного proceedings.

Треки 1–8 извлечены из `3774904.pdf`. Все 176 статей треков 9–10 собраны из открытых авторских
копий и официального ACM eReader и дополнительно преобразованы Marker в `md/`.
